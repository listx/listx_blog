#+title: Publishing the site

* Overview

This site used to be built with Hakyll; we would generate the site, then commit
all of the generated HTML and other static artifacts to a separate Git repo, and
then host that on GitHub Pages.

However, we've since moved to SourceHut for hosting. SourceHut's model is
slightly different because it just hosts a tarball of content, which is uploaded
to their server. So the key difference is that the generated site is /not/ a Git
repo.

Another difference is that we use Lilac to generate the HTML. It is
straightforward enough to use Lilac to write new content, but the Hakyll-era
content still needs to be included in the tarball because there are old URLs out
there that still reference it. See [[id:d33f8893-02be-4e99-9d53-0e2c274ba3d3][Old content]].

* Publish to SourceHut

** Old content
:PROPERTIES:
:ID:       d33f8893-02be-4e99-9d53-0e2c274ba3d3
:END:

Until we migrate all old posts (pre-2026) to use Lilac, we will have a body of
work which we'll need to still publish the old way. We don't want to maintain
the Hakyll build dependencies, so instead we just pull in the old statically
generated repo, then we overwrite it with any content generated by Lilac. Then
we tar it up and deploy to SourceHut. That way the old content won't be broken
(all of the old URLs will still work).

** Makefile

#+name: Makefile:publish
#+begin_src makefile
site.tar.gz: $(archive_file) weave vendor/mathjax vendor/<<mathjax-font>>-font vendor/google-fonts
	rm -f site.tar site.tar.gz
	git -C legacy-generated-repo reset --hard
	git -C codex reset --hard
	cd codex && git submodule update --init --recursive

	# (ref:Makefile:publish-fix-mathjax)
	<<fix-mathjax>>
	<<fix-jquery>>
	<<fix-google-fonts>>

	# (ref:Makefile:publish-legacy)
	tar cvf site.tar -C legacy-generated-repo --exclude='**/.*' .

	# (ref:Makefile:publish-site)
	tar rvf site.tar -C site .

	# (ref:Makefile:publish-codex)
	find -L codex -path 'codex/deps/elisp/lilac/deps' -prune -o \
		-type f \
		-not -path '*/.*' \
		\( -name '*.html' -o -name '*.css' -o -name '*.js' -o -name '*.svg' \) \
		| tar rvhf site.tar --hard-dereference --exclude='codex/deps/elisp/lilac/deps' -T -

	# (ref:Makefile:publish-mathjax)
	tar rvf site.tar vendor
	gzip site.tar

	# (ref:Makefile:publish-cleanup)
	git -C legacy-generated-repo reset --hard
	git -C codex reset --hard

# (ref:Makefile:publish-get-mathjax-fonts)
vendor/<<mathjax-font>>-font:
	./get-mathjax-fonts.sh

vendor/google-fonts:
	./get-google-fonts.sh

SRHT_TOKEN != cat .srht-pages-token 2>/dev/null || echo ""

publish: site.tar.gz
	@if [ -z "$(SRHT_TOKEN)" ]; then \
		echo "Error: .srht-pages-token is empty or missing." >&2; \
		exit 1; \
	fi
	@echo "Uploading site to SourceHut Pages..."
	@curl --oauth2-bearer "$(SRHT_TOKEN)" \
		-Fcontent=@site.tar.gz \
		https://pages.sr.ht/publish/funloop.org
	printf \
		'<meta http-equiv="refresh" content="0; url=https://funloop.org/">' > index.html && \
		tar -czf - index.html | \
		curl --oauth2-bearer "$(SRHT_TOKEN)" \
		-F content=@- \
		https://pages.sr.ht/publish/www.funloop.org
	touch publish
#+end_src

[[(Makefile:publish-legacy)]] bundles up the old legacy content into a tar file,
after which we tar up Lilac's woven content into the same tar file.

[[(Makefile:publish-site)]] publishes the main site; this comes after
[[(Makefile:publish-legacy)]] just in case we want to overwrite any old pages.

[[(Makefile:publish-codex)]] publishes the https://git.sr.ht/~listx/codex repo.

Publishing the site requires a personal access token from SourceHut, which we
ignore from our repo (checking it into Git would be a disaster!). The actual
command to publish is quite straightforward though, as we just need to invoke a
single ~curl~ command.

[[(Makefile:publish-cleanup)]] cleans up the submodule directories,
because fixing the MathJax results in modifying tracked files. This way we
reduce the chance of accidentally commiting those changes to the main repo
(because Git tracks whether a submodule is "dirty").

*** Fix MathJax

Because SourceHut does not allow pulling in MathJax over a CDN, we have to
modify the HTML files to use a locally vendored version
[[(Makefile:publish-fix-mathjax)]] via [[fix-mathjax]], and also include MathJax
dependencies in the tarball [[(Makefile:publish-mathjax)]].

#+name: fix-mathjax
#+begin_src sh
find legacy-generated-repo -type f -name "*.html" \
	-exec sed -i 's|https://cdnjs.cloudflare.com/ajax/libs/mathjax/2.7.2/MathJax.js?config=TeX-AMS-MML_HTMLorMML|/vendor/MathJax/tex-mml-chtml.js|g' {} +
find site -type f -name "*.html" \
	-exec sed -i 's|https://cdn.jsdelivr.net/npm/mathjax@4/tex-mml-chtml.js|/vendor/MathJax/tex-mml-chtml.js|g' {} +
find codex -path 'codex/deps' -prune -o \
	-type f -name "*.html" \
	-exec sed -i 's|https://cdn.jsdelivr.net/npm/mathjax@4.0.0-beta.4/tex-mml-chtml.js|/vendor/MathJax/tex-mml-chtml.js|g' {} +

# (ref:fix-mathjax-reference-local-mathjax-fonts)
find codex -path 'codex/deps' -prune -o -type f -name "*.html" -exec \
	<<sed-inject-mathjax-font-codex>> {} +

find legacy-generated-repo -type f -name "*.html" -exec \
	<<sed-inject-mathjax-font-legacy>> {} +

find site -type f -name "*.html" -exec \
	<<sed-inject-mathjax-font>> {} +
#+end_src

Apparently just including ~tex-mml-chtml.js~ is not enough, because it is missing
fonts. We have to download the fonts from NPM and then include it as well.

#+name: get-mathjax-fonts.sh
#+header: :tangle get-mathjax-fonts.sh
#+header: :shebang #!/usr/bin/env bash
#+begin_src bash
set -euo pipefail

FONT_PACKAGE="<<mathjax-font>>-font"
VERSION="4.1.2"

pushd vendor

if [[ -d "${FONT_PACKAGE}" ]]; then
	echo "${FONT_PACKAGE} directory already exists"
	exit
fi

curl -O "https://registry.npmjs.org/@mathjax/${FONT_PACKAGE}/-/${FONT_PACKAGE}-${VERSION}.tgz"
tar -xzvf "${FONT_PACKAGE}-${VERSION}.tgz"
mv package "${FONT_PACKAGE}"
rm "${FONT_PACKAGE}-${VERSION}.tgz"
#+end_src

We execute [[get-mathjax-fonts.sh]] at [[(Makefile:publish-get-mathjax-fonts)]] to
download the fonts and prepare it for inclusion into the ~vendor~ directory. The
only thing remaining is to reference it in the HTML files in
[[sed-inject-mathjax-font-codex]] [[(fix-mathjax-reference-local-mathjax-fonts)]].

Below we modify the HTML files depending on their "flavor". The critical piece
in each of the code blocks below is telling MathJax to load the fonts from the
local ~/vendor/<<mathjax-font>>-font~ directory. If we don't do this, then MathJax
still tries to load fonts from a CDN, which will break for SourceHut.

#+name: mathjax-font
#+begin_src txt
mathjax-newcm
#+end_src

#+name: sed-inject-mathjax-font-codex
#+begin_src sh
sed -i 's|output:[[:space:]]*{|loader: { paths: { "<<mathjax-font>>": "/vendor/<<mathjax-font>>-font" } },\
output: {|'
#+end_src

#+name: sed-inject-mathjax-font-legacy
#+begin_src sh
sed -i '/<script type="text\/x-mathjax-config">/,/<\/script>/c\
<script>\
  window.MathJax = {\
    tex: {\
      ams: {\
        multlineWidth: '\''85%'\''\
      },\
      tags: '\''ams'\'',\
      tagSide: '\''right'\'',\
      tagIndent: '\''.8em'\''\
    },\
    chtml: {\
      scale: 1.0,\
      displayAlign: '\''center'\'',\
      displayIndent: '\''0em'\''\
    },\
    svg: {\
      scale: 1.0,\
      displayAlign: '\''center'\'',\
      displayIndent: '\''0em'\''\
    },\
    loader: { paths: { "<<mathjax-font>>": "/vendor/<<mathjax-font>>-font" } },\
    output: {\
      font: '\''<<mathjax-font>>'\'',\
      displayOverflow: '\''overflow'\''\
    }\
  };\
</script>'
#+end_src

#+name: sed-inject-mathjax-font
#+begin_src sh
sed -i '/window\.MathJax[[:space:]]*=[[:space:]]*{/a\
  loader: { paths: { "<<mathjax-font>>": "/vendor/<<mathjax-font>>-font" } },\
  output: { font: "<<mathjax-font>>" },'
#+end_src

*** Fix Google fonts

We have to host the fonts directly as well, instead of pulling them over the
network from Google web fonts.

The first thing to do is to download the fonts locally.

#+name: get-google-fonts.sh
#+header: :tangle get-google-fonts.sh
#+header: :shebang #!/usr/bin/env bash
#+begin_src bash
set -euo pipefail

if [[ -d vendor/google-fonts ]]; then
	echo "vendor/google-fonts directory already exists"
	exit
fi

mkdir -p vendor/google-fonts

curl -fsSL -A 'Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36' \
'https://fonts.googleapis.com/css2?display=swap&family=Source+Code+Pro:ital,wght@0,400;0,700;1,400;1,700&family=Source+Sans+3:ital,wght@0,400;0,700;1,400;1,700&family=Source+Serif+4:ital,wght@0,400;0,700;1,400;1,700' \
-o vendor/google-fonts/google-fonts.css

# Filter specifically for links ending in .woff2
grep -o 'https://fonts.gstatic.com[^)]*\.woff2' \
	vendor/google-fonts/google-fonts.css |
	sort -u |
	while read -r url; do
		curl -fsSL "$url" -o "vendor/google-fonts/$(basename "$url")"
	done

sed -i -E \
's|https://fonts.gstatic.com/[^)]*/([^/)]+\.woff2)|/vendor/google-fonts/\1|g' \
vendor/google-fonts/google-fonts.css
#+end_src

Now make the HTML content refer to the local fonts.
[[(fix-google-fonts-use-source-serif-4)]] makes the old blog posts use "Source Serif
4", not "Source Serif Pro" (because the former is what we download).

#+name: fix-google-fonts
#+begin_src sh
find site codex legacy-generated-repo -path 'codex/deps' -prune -o \
	-type f -name "*.html" -exec \
	<<sed-use-local-google-fonts>> {} +

# (ref:fix-google-fonts-use-source-serif-4)
sed -i 's|Source Serif Pro|Source Serif 4|g' legacy-generated-repo/css/base.css
#+end_src

#+name: sed-use-local-google-fonts
#+begin_src sh
sed -i \
's|href="https://fonts\.googleapis\.com[^"]*"|href="/vendor/google-fonts/google-fonts.css"|g'
#+end_src

#+name: Makefile:Hakyll
#+begin_src makefile
# This Makefile is expected to be run inside a nix-shell.

PROJ_ROOT := $(shell git rev-parse --show-toplevel)

BLOG_PORT?=8020

.PHONY: all

	cabal build -- base >/dev/null

.PHONY: gen-js

	cabal update
.PHONY: cabal-update

	cabal build
.PHONY: build-binaries

	cabal run -- blog rebuild
.PHONY: build-site

watch: build-binaries
	cabal run -- blog watch --host $(BLOG_ADDR) --port $(BLOG_PORT)

nixpkgs_stable_channel := nixos-24.05

	niv update nixpkgs --branch $(nixpkgs_stable_channel)
	niv update
	touch update-deps

The local ~listx.github.io~ folder used to have the Github repo which held the
generated content. Hakyll would by default publish to ~_site~, so the script below
would sync these two with ~rsync~.

#+begin_src bash
dest='listx.github.io/'
targ='_site/'

if [[ ! -d $targ ]]; then
    echo "\`$targ' directory missing"
    exit 1
elif [[ ! -d $dest ]]; then
    echo "\`$dest' directory missing"
    exit 1
fi

rsync -ahP --no-whole-file --inplace --delete --exclude=.git\* $targ $dest
#+end_src
